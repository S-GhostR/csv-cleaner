# CSV Cleaner

Простой инструмент на Python для очистки и проверки CSV-файлов.

## Возможности

- Удаление лишних пробелов в значениях.
- Удаление повторяющихся записей.
- Проверка возраста (от 1 до 120 лет).
- Проверка наличия обязательных столбцов (`name`, `age`, `city`).
- Проверка структуры CSV-файла.
- Обработка пустых и некорректных записей.
- Сохранение очищенных данных в отдельный файл.
- Вывод статистики обработки.

## Используемые технологии

- Python 3
- `csv`
- `pathlib`

## Структура проекта

```text
csv-cleaner/
├── data/       # Исходные CSV-файлы
├── output/     # Очищенные CSV-файлы
├── main.py     # Основной код программы
└── README.md
```

## Запуск

1. Скачайте или клонируйте репозиторий.
2. Поместите исходный CSV-файл в папку `data`.
3. Запустите программу:

   ```bash
   python main.py
   ```

4. Введите имя CSV-файла.

Очищенный файл появится в папке `output`. К исходному файлу программа не обращается с целью перезаписи.

## Формат входного файла

CSV-файл должен содержать следующие обязательные столбцы:

```csv
name,age,city
Иван,20,Москва
Пётр,25,Казань
Анна,19,Самара
```

Дополнительные столбцы также поддерживаются и сохраняются при обработке.
