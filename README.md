CSV Cleaner

Простой инструмент на Python для очистки и проверки CSV-файлов.

Возможности

- Удаление лишних пробелов.
- Удаление дубликатов.
- Проверка корректности возраста.
- Проверка обязательных столбцов.
- Обработка пустых CSV-файлов.
- Сохранение очищенных данных.
- Вывод статистики обработки.

Используемые технологии

- Python 3
- CSV
- pathlib

Структура проекта

csv-cleaner/
├── data/
├── output/
├── main.py
└── README.md

Запуск

1. Скачайте репозиторий.
2. Поместите исходный CSV-файл в папку "data".
3. Запустите "main.py".
4. Введите имя CSV-файла.

Очищенный файл появится в папке "output".
